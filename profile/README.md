## About This Page

This organization is intended to serve as:
1. A storage location for data, scripts, and process documentation
2. A more granular and accessible task tracking system to be used in conjunction with Notion.
   
As a storage location, GitHub is more useful than Drive with respect to access - it is easy to control exactly what is allowed to be added, modified, or deleted, and it is easy to version control any of these document types as much as is necessary.

As a task tracking system, GitHub is readily used in conjunction with a more broad, team-wide tracking system like Notion because the combined system of issues, subissues, comments, and pull requests allows team-wide access to the state of any task automatically, but \[as far as I can tell] does not work extremely well with specific date ranges. This system can be used for updates on each part of a project, ultimately referenced to the Notion calendar.
